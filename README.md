## 💡 Descripción del Proyecto

`ProyectoLibreriasSwing` aborda los retos comunes en el desarrollo de interfaces gráficas con Java Swing, mostrando de forma clara cómo incorporar dependencias externas para hacer crecer las capacidades visuales y funcionales del framework nativo. Su propósito es servir como una base sólida, modular y fácil de mantener para proyectos de desarrollo de software en Java.

---

## ✨ Características Clave

* 🚀 **Integración Práctica:** Ejemplos directos sobre cómo añadir y gestionar librerías externas en proyectos Swing.
* 🎨 **Mejoras Visuales:** Implementación de componentes gráficos más modernos y atractivos que los predeterminados.
* 🏗️ **Arquitectura Modular:** Estructura limpia diseñada para facilitar la reutilización de código y el mantenimiento a largo plazo.
* 📚 **Enfoque Educativo:** Código fuente bien documentado y comentado, ideal para comprender buenas prácticas de desarrollo en escritorio.

## ⚙️ Configuración y Ejecución Local

### Prerrequisitos

Para ejecutar y desarrollar este proyecto en tu equipo, necesitarás:

* **Java Development Kit (JDK):** Versión 8 o superior instalada.
* **Entorno de Desarrollo (IDE):** IntelliJ IDEA (recomendado), Eclipse o NetBeans.

### Pasos de Instalación

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/Mario-Si3ri/ProyectoLibreriasSwing.git
   ```
2. **Abrir el proyecto en tu IDE:**
   ```bash
   Abre IntelliJ IDEA (o tu IDE de preferencia).
   Selecciona Open (Abrir) y busca la carpeta clonada del proyecto.
   ```
3. **Configurar el JDK:**
   ```bash
   Verifica que el proyecto tenga asignada una versión compatible del JDK en la configuración del entorno de desarrollo.
   ```

4. **Ejecutar la aplicación:**
   ```bash
   Localiza la clase principal que contiene el método main dentro del directorio ProyectoLibrerias/ y ejecútala.
   ```
